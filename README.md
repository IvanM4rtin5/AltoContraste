# Cor de Fundo

Este projeto foi desenvolvido durante o curso de **Desenvolvimento Web** da **Fundação Bradesco**. Ele permite alterar a cor de fundo de uma página web de forma simples, oferecendo duas opções de tema: vermelho e preto. O usuário pode interagir com a página clicando em um botão para alterar o fundo.

## Funcionalidades

- Permite alterar a cor de fundo da página para vermelho ou preto.
- Design responsivo, adequado para dispositivos móveis.
- Desenvolvido com HTML, CSS e JavaScript para manipulação da cor do fundo.

## Tecnologias utilizadas

- **HTML5**: Para a estrutura da página.
- **CSS**: Para o estilo e design da página.
- **JavaScript**: Para a funcionalidade de alteração do tema (cor de fundo).
